# SimpleSummon

[![Unity Windows Build](https://github.com/Thisman/SimpleSummon/actions/workflows/unity-windows.yml/badge.svg?branch=main)](https://github.com/Thisman/SimpleSummon/actions/workflows/unity-windows.yml)

Low-poly cooperative game about an inexperienced mage whose ritual mistakes affect the summoned demon.

## CI status and reports

The badge above always shows the current status of the `main` branch. Every CI run executes Unity EditMode and PlayMode tests, collects code coverage for the Domain, Application, Runtime, and Network assemblies, and then builds the Windows player after successful tests.

- [Latest CI run and test/coverage artifacts](https://github.com/Thisman/SimpleSummon/actions/workflows/unity-windows.yml)
- [Latest downloadable main build](https://github.com/Thisman/SimpleSummon/releases/tag/latest-main)

Open a completed workflow run to see the coverage percentages in its Summary. The `unity-coverage` artifact contains the full HTML and XML reports.
